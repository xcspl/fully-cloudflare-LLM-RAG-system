## Data Flow

```
Ingestion:
  python scripts/ingest-data.py → Data Worker (/ingest)
    → D1 store (INSERT OR REPLACE, deterministic slug)
    → canonicalize via AI Gateway (custom-deep2/DeepSeek V4 Flash)
    → bge-m3 embed via Workers AI
    → Vectorize upsert with metadata pointer

Chat:
  CF Pages (static/index.html) → Chat Worker (/chat)
    → D1 (session load, system message select)
    → Tool loop: LLM decides → search_knowledge_base → Data Worker (/search)
    → Final LLM call → SSE stream or JSON response
    → D1 (session save)
```

## Ingestion dedup

`slug = MD5(source + JSON.stringify(data, sort_keys=True))`. Auto-generated by ingest script. `INSERT OR REPLACE` in Worker. Re-running same file = upsert, no duplicates.
