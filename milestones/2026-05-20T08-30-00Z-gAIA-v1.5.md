## What We Built

### Session Persistence Overhaul

Replaced the `sessions.messages` JSON blob with a proper `chat_messages` table (7 columns, one row per item). Each message — user, assistant, tool call, search result — is a row with role, content, and timestamp.

- **50-item context window** loaded from `chat_messages` per request
- **Tool markers compacted**: `assistant(tool_calls)` → `[search: "query"]` before saving
- **Think blocks stripped** from saved assistant messages
- **D1 batch inserts** for performance

### Tool Framework

Three tools available to the LLM:

| Tool | Backend | Purpose |
|------|---------|---------|
| `search_knowledge_base` | Data Worker → Vectorize | RAG over org docs, guides, data |
| `get_current_time` | Worker inline | GMT time on demand |
| `search_chat_history` | D1 chat_messages | Past conversation search |

`WEB_SEARCH` tool defined but commented out — ready when needed.

### User Profile System (Designed)

Compaction trigger: when a user starts a new session (no existing session_id for that user), the Worker background-compacts the previous session + existing profile → new profile. Profile injected into system prompt on next request. LLM knows the user from first message.

One-session gap accepted for now — profile is always one compaction cycle behind, but auto-closes mid-session.

### EarthTeam Identity

- Identity block injected every inference ("we", Freeland, Earth Credits, Solutions Map)
- GMT timestamp with year/month injected per request
- System messages keyword-triggered from D1
