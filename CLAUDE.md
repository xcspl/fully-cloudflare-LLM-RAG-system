# gAIa — AI Chatbot Framework

Three components: Chat Worker (API), Data Worker (ingest/search), CF Pages (UI). Shared D1, AI Gateway, bge-m3.

## Architecture

```
CF Pages (gaia-chat.pages.dev)
  └── static/index.html → fetch SSE → gaia-api.earth-team.org

Chat Worker "gaia" (gaia-api.earth-team.org)  — API only
  ├── D1 (sessions, system_messages)
  ├── Data Worker: service binding (/search)
  │     └── Vectorize + D1 + bge-m3
  └── AI Gateway (et-gaia) → custom-minimax (chat) / custom-deep2 (canonical)

Data Worker "gaia-data" (gaia-data.sumanta-7a8.workers.dev)
  ├── /ingest — D1 store → canonicalize (DeepSeek) → bge-m3 embed → Vectorize
  ├── /search — embed query → Vectorize → D1 fetch
  └── /health
```

## Routes

| Worker | Route | Method | Description |
|--------|-------|--------|-------------|
| gaia | `/chat` | POST | Tool-based RAG chat, SSE streaming or JSON |
| gaia | `/chat/history` | GET | Session history per user |
| gaia | `/health` | GET | D1 + Data Worker connectivity |
| gaia-data | `/ingest` | POST | JSON → D1 → canonicalize → embed → Vectorize |
| gaia-data | `/search` | POST | Embed query → Vectorize → D1 → results |
| gaia-data | `/health` | GET | D1 + AI + Vectorize |

## Ingestion (idempotent)

```json
{
  "data": { "title": "...", "content": "..." },
  "key_keys": ["title", "content"],
  "source": "earth-team-main-site",
  "source_url": "https://www.earth-team.org/about",
  "slug": "optional-override"
}
```

Slug = `MD5(source + JSON.stringify(data))` — auto-generated if not provided. `INSERT OR REPLACE` = safe to re-run. Same data = same slug = no duplicate.

## Vectorize metadata keys

`canonical_text`, `d1_db_id`, `d1_row_id`, `external_url`, `user_id` (chat only), `embedding_model`

## Deploy

```bash
cd worker && npx wrangler deploy --name gaia
cd data-worker && npx wrangler deploy
# Chat UI: npx wrangler pages deploy static/ --project-name gaia-chat
```

Secrets needed: `CF_AIG_TOKEN` on gaia and gaia-data Workers.

## Key gotchas

- `VECTORIZE.query()` returns `{ matches, count }`, NOT `{ data }`
- `env.AI.run()` returns nested `{ data: [[...]] }` — always `Array.from(data[0])`
- Vectorize metadata values must be strings — omit null keys
- `ExecutionContext` is runtime-injected, not constructable
- AI Gateway auth header is `cf-aig-authorization`, not `Authorization`
- `wrangler deploy` from worker/ dir must use `--name gaia` (not `--name t--pp`)
- Delete any root-level `wrangler.jsonc` auto-generated by wrangler
- Minimax: no `role: tool`, no `stream + tools` together
- Inter-Worker calls: use Service Bindings, not `workers.dev` URLs
- CORS: `Access-Control-Allow-Origin: *` on gaia Worker

## What NOT to do

- Don't hardcode domain knowledge or project names in code
- Don't embed raw content directly — always canonicalize first
- Don't use brand names in variable/function names or comments
- Don't log API keys or full prompts to observability
